# 0x01 - Notes and Templates

This folder stores reusable bug bounty documentation templates.

## Current Contents

- `BBTNT.md`: Bug Bounty Testing Note Template for tracking scope, test ideas, findings, and evidence.

## Suggested Workflow

1. Copy the template for each new target or program.
2. Fill the sections as testing progresses.
3. Keep references and proof-of-concept notes linked to final reports.
